# Mission Book 文档

文档统一收敛在 [`v1.0/`](v1.0/索引.md)，作为 Mission Book 的完整规格。

`v1.0/` 描述的是**要建成什么**，不代表仓库当前已有对应实现。仓库处于重新实现阶段，进度以代码和实际验收为准。

`ui设计手册/` 为 UI 设计稿图片，是**界面视觉与布局的事实标准**（不属于文字规格，但优先级高于文字描述）。

## 文档结构

| 类别 | 文档 |
|---|---|
| 为什么做 | 产品纲领 |
| 是什么 | 领域模型、数据模型 |
| 做什么 | 本地应用规格、界面与交互 |
| 怎么做 | 数据落地与平台 |
| 以后做什么 | 未来方向 |

阅读顺序见 [`v1.0/索引.md`](v1.0/索引.md)。

## 文档约定

- 全部文档共用同一套版本，正文中不出现文档版本号。
- 术语只在《领域模型》定义一次，其他文档引用而不重述；同一句话不写两遍。
- 产品纲领 / 领域模型 / 数据模型是上位文档，实现规格与之冲突时以上位为准。
- 文档描述目标行为，不声称已实现。
- **只建模当前真实存在的东西**：没有产生路径的对象、字段、枚举不进数据模型，统一放在《未来方向》，并且不得以空表、占位接口或未使用字段的形式提前进入工程。
- 具体目录结构与类命名由实现者决定，规格不锁定实现结构。
- 被取代的设计不保留在文档中，历史可经 git 回溯。
