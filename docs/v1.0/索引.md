# Mission Book — 规格索引

本目录是 Mission Book 的完整规格，描述**要建成什么**，不代表已经存在对应实现。

## 阅读顺序

### 一、为什么做

1. [产品纲领](产品纲领.md) — 产品宪法：核心思想、AI 行为边界、规划原则与长期指标。

### 二、是什么

2. [领域模型](领域模型.md) — 稳定领域语言与 Mission 生命周期。**本文档是术语的唯一来源。**
3. [数据模型](数据模型.md) — 当前这一版最少需要保存哪些事实、Source of Truth 与一致性约束。

### 三、做什么

4. [本地应用规格](本地应用规格.md) — 这一版的产品边界、必须包含与不包含、验收标准与完成定义。
5. [界面与交互](界面与交互.md) — 信息架构、页面结构、核心交互链与视觉基调。

### 四、怎么做

6. [数据落地与平台](数据落地与平台.md) — 存储规则、事务边界、Migration、Goal Outline 导入协议与平台约束。

### 五、以后做什么

7. [未来方向](未来方向.md) — 已经想过、当前不实现的能力。**不得提前进入工程。**

## 约束

- 领域层文档（产品纲领 / 领域模型 / 数据模型）是实现层文档的上位：冲突时以上位为准。
- 同一句话只写一遍。术语只在 [领域模型](领域模型.md) 定义，其他文档引用而不重述。
- 文档描述目标行为，不声称已实现；任何"已完成"的结论必须来自代码与实测。
- 具体目录结构与类命名由实现者决定，规格只约束依赖方向与职责划分。
- 本目录不保留历史版本。旧版本设计与历次验收记录见 git 历史。
